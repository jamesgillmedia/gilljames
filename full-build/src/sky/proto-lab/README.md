# Prototype lab — 12 Nov 2026

Working pages for six “test hard” concepts, each with A / B / C proposals you can switch on the page. Local only. Nothing was pushed.

Serve over http so audio and video load:

    python3 -m http.server 8765 --directory /workspace/proto-lab-1112

Then open http://127.0.0.1:8765/

- `tile-reveal/` — each tile its own treatment, from the 4:23 moment
- `sound-starchart/` — songs as stars; official dotted star-chart waveform and player bar; audio plays
- `moon-ripple/` — touch ripples, nothing opens
- `mark-tune/` — tune menu in every room; values saved on the device; Reset; photographs not graded
- `spaces-walk/` — walkthrough into Spirit Eye · the forest garden
- `objects-fly/` — fly through the rings toward JOIO CUP

Arrow keys or A / B / C also switch proposals. `?v=B` (or C) opens a chosen proposal. `?mid=1` freezes a mid-state on tile-reveal, moon-ripple, and objects-fly, for stills.
